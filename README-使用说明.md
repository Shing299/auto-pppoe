# PPPoE 一键拨号脚本 · 使用说明

双击 `pppoe-connect.bat` 就能拨号上网。第一次要输账号密码，之后不再问。

---

## 一、怎么用

1. 把 `pppoe-connect.bat` 和 `pppoe-core.ps1` **放在同一个文件夹里**（不能只复制 bat）。
2. **第一次**双击 `pppoe-connect.bat`：
   - 提示「请输入宽带账号」→ 输入运营商给的拨号账号（形如 `0512xxxxxxx@163.gd` 或手机号）
   - 提示「请输入宽带密码」→ 输入拨号密码
   - 提示「连接名称」→ 直接回车用默认名 `PPPoE-AutoDial`；如果想让脚本使用系统里已有的连接（比如「宽带连接」），在这一步把那个名字打进去
   - 三个都填完后，脚本会自动生成 `pppoe-config.ini` 并立即开始拨号
3. **以后**每次双击，脚本直接读 `pppoe-config.ini` 拨号，不再询问。

> 想改账号密码？把 `pppoe-config.ini` **删掉**，再双击一次即可重新录入。

---

## 二、文件说明

| 文件 | 作用 |
|---|---|
| `pppoe-connect.bat` | 主程序，双击这个 |
| `pppoe-core.ps1` | 拨号核心逻辑（bat 调用，不要单独运行） |
| `pppoe-config.ini` | **第一次运行后自动生成**，保存账号 / 密码 / 连接名 |

### 生成的 `pppoe-config.ini` 长这样

```ini
user=0512xxxxxxx@163.gd
pass=你的宽带密码
entry=PPPoE-AutoDial
```

`entry=` 这一行可以手改：填系统里已有的连接名（例如 `宽带连接`），脚本就直接用那条，不新建。

---

## 三、开机自动拨号（可选）

按 `Win + R`，输入 `shell:startup` 回车，把 `pppoe-connect.bat` 的**快捷方式**拖进去。
下次开机进桌面就会自动拨号。

---

## 四、可能要管理员权限

脚本会在**当前用户的电话簿**里创建一条名为 `PPPoE-AutoDial` 的连接（不影响、也不覆盖你已有的「宽带连接」）。

如果首次运行报错 **623 / 624 / 无法写入电话簿**：
→ 右键 `pppoe-connect.bat` → **以管理员身份运行**一次即可。

> 不想新建连接、想直接用系统里已有的那条？首次运行在「连接名称」处填 `宽带连接` 即可，这种情况**不需要管理员权限**。

---

## 五、常见报错速查

| 错误码 | 含义 | 怎么办 |
|---|---|---|
| 691 | 账号或密码错误 | 删掉 `pppoe-config.ini`，重新双击录入 |
| 678 / 718 | 对方无响应 | 检查网线、光猫电源、光猫是否已桥接 |
| 651 | 网卡/驱动问题 | 重装网卡驱动，或换网口 |
| 623 / 624 | 找不到/无法写入条目 | 用管理员身份运行 |
| 720 | PPP 无法建立连接 | 多半是**上层已经是路由拨号**，本机再拨没用（见下） |

---

## ⚠️ 六、重要：先确认你的网络拓扑

脚本本身没问题，但 **PPPoE 拨号要求本机（或路由器）二层直连光猫的桥接口**。

**怎么判断？** 在能上网的状态下打开 CMD，输入：

```
ipconfig
```

- 如果看到 IPv4 地址是 **192.168.x.x / 10.x.x.x**，默认网关是路由器 → **你现在是「路由器拨号」模式**，本机再跑 PPPoE 是拨不通的（会卡在 678/720）。
  想用本机拨号，需要先把**光猫改桥接**，并让路由器也改成桥接/AP 模式（或把电脑网线直连光猫）。
- 如果本机拿不到 192.168 之类的内网地址、网关为空 → 说明就是等本机拨号的环境，脚本直接能用。

---

## 七、安全提醒

`pppoe-config.ini` 里的密码是**明文**保存的（和 Windows 自带的「宽带连接」记住密码是同一类做法）。

- 这台电脑是**你自己专用** → 无所谓，方便第一。
- 是**公用/多人使用**的电脑 → 建议改用系统自带的「宽带连接」勾选「记住密码」，或者用完手动删除 `pppoe-config.ini`。

脚本不会把密码上传到任何地方，全程只调用 Windows 自带的 `rasdial.exe`。
